# Hubbard Plumbing & Heating — Site Design Concept

Home page design mockup for a new site for Hubbard Plumbing & Heating, Inc. (1944 Ocean St, Marshfield, MA).

`index.html` is a single-file, self-contained design concept — fonts and icons are inlined, no build step required. Open it directly in a browser.

**Status:** design concept for internal review. Several details are draft/unconfirmed and need sign-off from Hubbard Plumbing & Heating before this becomes a real, live site:
- Service-area town list
- Response-time/callback commitment language
- Instagram link (account match to this business unconfirmed)
- Hours of operation

Testimonials quoted on the page are sourced from Birdeye, Nextdoor, and BBB (September 2026).
